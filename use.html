How you use what you already saved

You have seen the reels. This page says what the thing is, and the one way it fits your desk. Your desk is a security firm plus a local model. Not a sports app. Not a posting farm.

The desk, in one pass

An officer writes what they saw. That note is a file. A local model, Qwen on your ROG box when it fits, is only allowed to read that file. It writes a second file, the draft. If a fact is not in the note, the draft says missing. You sign it. Nothing sends itself.

Everything below is either a piece of that loop, or it is noise.

Shannon

Shannon is a tester for a website you own. People call it Claude Code for hackers because it lives in the same terminal and takes a job. The job is check this app. It writes notes in stages. First it lists what it sees. Then it writes findings. Then it writes a report. Each stage is a file. The next stage reads the file.

How you use it: not on a stranger’s site. On your own overlay page, or a client site only after they ask in writing. You do not need the attack steps. You need the stage files. Your version is smaller. Stage one is the officer note. Stage two is the draft. Stage three is your signature. That is the whole product until it is boring.

The uncensored reel

He built, or rented, a chat that will answer anything, and he sends the link if you comment. No name was on the page. The user count is his.

How you use the idea: two model files on your machine. The normal Qwen writes the client draft. A looser file can brainstorm internal wording. The client file is the one that ships. You do not send incident notes to his site. You do not wait on the comment word.

Mods and the cheap-model split

A mod is a small add-on inside Claude Code. One reel says a session can message another, the window can become a dashboard, and easy work can go to a cheaper model. Flux said the same split: Qwen sorts, a stronger model decides.

How you use it: the local Qwen sorts the note. It lists what is present and what is missing. You, or a stronger model later, write the sentences. They do not talk. The sort is a file. The draft is a second file. Sixty agents and a shared memory can wait. One sorter is the mod you actually need.

Do not let it fill the blank

Champ’s reel is the rule you already have. A model sees a title and invents the page. He stopped trusting that. A scraper does not fix it.

How you use it: the draft may quote the note. It may say missing. It may not guess a badge number, a time, or a threat score. If you later add a research step, it has to paste the source line under the claim. No source line, no claim.

The stadium page

Someone asked Claude for a 3D stadium where you click a seat and see the view. The page is the product. The model only built the page.

How you use it: your stream overlay is the same shape, flatter. A page with three fields. Name. Score. Note. OBS shows that page. A text file fills the fields. You read the file before it goes on the live scene. You do not need the 3D stadium.

Hyperframes

Hyperframes turns a web page into a short video. Kevin used it so an agent could render a clip without opening an editor.

How you use it: after the report loop works, one approved draft can become a 10-second title card for a post. Not before. The report is the job. The clip is a copy of the report, not a new story.

Keys and the env file

The secrets reel says people leave API keys in public code. The fix is a private env file that git ignores.

How you use it: Instagram tokens, YouTube tokens, and model keys never go in the learning repo, a screenshot, or a lesson. If a reel says comment and I’ll send the key, that is a funnel. You make your own key in the provider’s site and keep it off the page.

Terminal, Ollama, Claude Code

NetworkChuck’s lesson is the install order. The terminal can see a folder. The browser cannot, unless you paste. Gemini is the free start. OpenCode can point at a local model. Claude Code is the paid builder. Ollama holds the model file. Tech With Tim’s lesson is pull a small model, run one prompt, write down the tag, then try a bigger file.

How you use it on the ROG box: install Ollama. Pull a small Qwen. Run the incident skill on a fake note. If the 27B file does not fit the 8 GB card, leave it. Two cards are not one pool until nvidia-smi and a real run say so.

Cole and Indy, the harness

Cole’s lesson is four parts: model, prompt, one tool, a trace of what it did. Indy’s lesson is a standing-order file and a second folder so a second worker cannot overwrite the note.

How you use it: the standing order is the incident skill. The tool is “read this file, write that file.” The trace is the validator. A second worker does not exist yet.

Fact or Hype, screenshot to code

itstundeanthony’s reel tags alassafi.ai and asks fact or hype. The caption does not name a repo. Comments describe a screenshot or URL clone, including pasted screenshots in Claude Code. The matching public repo, from Ahmed Alassafi’s own short, is github.com/abi/screenshot-to-code.

How you use it: a screenshot goes in, an HTML file comes out, you read the file. Same shape as the officer note. Do not clone a site you do not own. Do not put the API keys from that README into this repo.

Leave these

Camofox is a stealth browser. It does not go on a client desk. The trading repos are a different business. The game-port reel is nostalgia. The color-wheel reel is thumbnail taste, later. The scraper-for-store-prices reel is a vendor. Mimic, the tool that watches an app and emits Python, is a caption claim. Cloning a company’s private API is not your build. Comment-word reels with no name on the page stay funnels.

Order of work

  1. Fake incident note in a folder.
  2. Small local model writes a second file. Missing stays missing.
  3. You sign it.
  4. Only then an overlay page for the stream, filled from a file you approve.
  5. A clip tool after that, and only from an approved draft.

# Directory

You send Instagram reels, YouTube videos, and other links. Each one is processed into a different place so the desk becomes a database you can learn from.

| Place | What lands there |
|---|---|
| Inbox | Link, date, status |
| Guide | Reading section in plain language |
| Skill | A repeatable job, only when the link actually has one |
| Limits | Locked, unpaid, or unverified |

Current entries are in inbox.md.

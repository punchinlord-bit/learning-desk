25-minute exclusion filter

Polymarket perps note · board on min25.html

Binary contracts settle at 0 or 1. A $2,000 move and a $1 move pay the same on a binary. That is the wrong instrument for a price-magnitude scalp. Polymarket Perps, described as launched September 3, 2026, is a different product: up to 20x, hourly funding capped at ±4 percent, 2.5 percent maintenance, isolated margin, pUSD, U.S. orders blocked. Hyperliquid is the handoff’s preference for dollar-delta. Depth and spreads were not measured side by side. That preference is architectural, not a fill test.

Rule: 30 closed candles logged before a gate changes. The draft function returns true only when every check passes. It does not send an order.

function evaluate25mSetup(candle, macroRisk, vwap, ema20, rsi, dailyLow, tf1H, tf4H) {
  if (macroRisk.score > 0.7 && macroRisk.weeklyTrend === "DOWN") return false;
  if (candle.isWickOnly) return false;
  const didSweep = candle.low < dailyLow;
  const closedAboveLow = candle.close > dailyLow;
  const isGreen = candle.close > candle.open;
  if (!didSweep || !closedAboveLow || !isGreen) return false;
  if (!(candle.close > vwap.value && candle.close > ema20.value && rsi.value > 50)) return false;
  if (tf1H.trend !== "BULLISH" || tf4H.trend !== "BULLISH") return false;
  return true; // draft only. no order.
}

Desk: draft file, human sign, then a row on the overlay. No order button.
